Architecture

CLIENT / WEB BROWSER
        │  (only public entry point)
        ▼
VIRTUAL DATABASE LAYER
 ├─ Authentication (JWT)
 ├─ English / SQL validation
 ├─ Classification and trust policy
 ├─ Adaptive query router
 └─ Audit logging
        │
        ├──────────► TRUSTED NODE       (sensitive processing)
        ├──────────► SEMI-TRUSTED NODE  (approved processing)
        └──────────► NON-TRUSTED NODE   (public/internal read-only)

Physical database nodes are never directly exposed to the client.

Protected flow

A request is translated/parsed, checked against table and column classification, assigned to an eligible node, and recorded. Learning can rank safe nodes but cannot bypass trust policy.
